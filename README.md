# SpaceSATBuild

SpaceSATBuild is a beginner-friendly satellite builder. Choose hardware, explore how your selections affect a spacecraft concept, and save or share designs through text-file export and import.

## Features

- Choose a mission and browse satellite buses, batteries, solar hardware, payloads, communications, and other systems.
- Add custom components with optional mass, battery capacity, solar output, payload power, data rate, payload limit, power draw, notes, and a source link.
- See the spacecraft preview and design statistics update as you change components.
- View a five-star completeness rating based on selected system categories. It is a prototype rating, not an engineering assessment.
- Export a design to a `.txt` file and import a SpaceSATBuild design file later.
- Read about the creator and visit the GitHub, YouTube, and Modrinth profiles from the About Me tab.

## Run it

No installation or build step is required. Open `index.html` in a modern web browser.

## Project files

- `index.html` — page structure and content
- `styles.css` — layout, colors, and responsive styling
- `app.js` — component selection, preview updates, rating, and design import/export

## Hardware note

Catalog entries are examples of published products. Their inclusion does not mean that components are compatible or that a spacecraft design is ready to build or fly. Check manufacturer documentation and consult qualified aerospace engineers before using hardware in a real mission. Custom entries are user-provided and are marked unverified.

## Built with

HTML, CSS, and vanilla JavaScript.
