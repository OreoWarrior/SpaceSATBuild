# #OWH02-SpaceSATBuild

SpaceSATBuild is a beginner-friendly satellite builder for exploring spacecraft concepts. Choose a mission, select hardware references, and see how the configuration changes the satellite preview and its key stats.

## ✨ Features

### 🛰️ Mission choices
Create a concept for Earth observation, communications, or space science. Each mission changes the workspace description and the mission label in the preview.

### 🧩 Hardware catalog
Explore published examples of satellite buses, batteries, solar hardware, payloads, communications systems, and other spacecraft components. Product links lead to manufacturer references when available.

### 📊 Live satellite stats
See selected component details such as payload allowance, available payload power, battery capacity, solar output, data link, and other design indicators. The small satellite profile and five-star rating update as the design changes.

The rating is a prototype completeness indicator based on selected system categories. It is not a measure of mission success, safety, or real spacecraft performance.

### ✏️ Custom components
Add your own component names and specifications, such as mass, capacity, solar output, payload power, data rate, or source link. Custom entries are marked as unverified.

### 🔭 Interactive preview
View a concept rendering of the satellite, rotate or zoom the preview, and use the top-bar controls to zoom the whole website.

### 💾 Export and import
Export a design to a text file, then import that file later to restore its mission, component selections, and custom components.

### 📱 Responsive interface
The layout adapts to desktop and mobile screens. The project uses plain HTML, CSS, and JavaScript without a framework or build step.

## 🚀 Run it

1. Download or clone the repository.
2. Open `index.html` in a modern browser.
3. Choose a mission and start adding components.

No installation is required.

## 🎯 Project goal

SpaceSATBuild is a personal learning project designed to make satellite systems easier to explore. It helps users see how changing example components affects a spacecraft concept.

## ⚠️ Hardware note

Catalog items are published product examples, not a compatible or flight-ready parts list. Compatibility, interfaces, structural fit, power budgets, thermal behavior, orbital requirements, and mission performance have not been verified. Consult manufacturer documentation and qualified aerospace engineers before using hardware in a real mission.

## 🛠️ Built with

- HTML5 — page structure
- CSS3 — styling and responsive layout
- Vanilla JavaScript — component selection, preview updates, stats, and design-file import/export
